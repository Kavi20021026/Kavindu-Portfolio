## 💼 Personal Portfolio Website

This is my personal portfolio website showcasing my skills, projects, and experience as an HNDIT Undergraduate and aspiring software developer.

## 🚀 Features
Responsive design (mobile-friendly)
Dark/Light mode toggle
Typing animation
Project showcase with pop-up details
Smooth scrolling and animations

## 🛠️ Technologies Used

### 💻 Frontend

* HTML5
* CSS3 (Flexbox, Grid, Animations)
* JavaScript (DOM Manipulation, Interactivity)

### 🎨 UI / UX Features

* Responsive Design (Mobile-Friendly)
* Dark / Light Mode Toggle
* Typing Animation
* Smooth Scrolling & Animations

### 📂 Projects & Functionality

* Interactive Project Cards with Modal Popups
* Image Gallery for Project Screenshots
* Dynamic Navigation (Hamburger Menu)

### 📡 Communication / Integration

* Contact Form powered by Formspree (Form Handling & Email Delivery)
* WhatsApp Integration (Direct Messaging via API link)

### ⚙️ Tools & Platforms

* Git & GitHub (Version Control)
* Netlify (Deployment)
  
## 📩 Contact Feature

The contact form is fully functional using Formspree, allowing users to send messages directly to my email without requiring a custom backend.
